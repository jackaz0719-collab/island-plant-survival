# 無人島植物サバイバル

植物への興味を高めることを目的とした教育型サバイバルゲームです。

`index.html` をブラウザで開くと起動します。外部ライブラリは使用していません。

## 操作

- 矢印キーまたはWASDで移動
- 植物に近づくと調査パネルが表示
- 1日最大5種類まで採取
- 夜に採取した植物から必ず1種類を選んで食べる

## 画像

植物画像は `Image/植物名.png` を参照します。

例:

- `Image/ヨモギ.png`
- `Image/ドクゼリ.png`
- `Image/オオキンケイギク.png`

画像が存在しない場合は「画像が設定されていません」と表示します。
